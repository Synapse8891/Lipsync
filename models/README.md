# 学習済みモデルの保存先

`kotoba_int8.npz` は2026年10月25日に学習が完了した試作モデルです。修正済みの `ctc-midpoint-v2` ラベルを使っています。

- ネットワーク: 468 → 256 → 128 → 16
- 155,024パラメータ、143,433 bytes、int8保存・float32推論
- 6候補の検証比較で選択した候補6、シード73、最良エポック39
- SHA-256: `208f761d7ad7b107e2059c9a2eed700040353c3c47abc8dd195624ba69551d77`
- 自動ラベルとのテスト一致率: 全体64.66%、日本語68.67%、英語53.99%
- 無音以外のフレームでの一致率: 全体49.56%。人手による実際の口形精度・自然呼吸の精度は未検証

目標80%以上を達成したモデルではありません。詳しくは [評価結果](../reports/RESULTS.md)、再学習は [学習手順](../docs/TRAINING_JA.md) を参照してください。
