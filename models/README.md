# 学習済みモデル

`kotoba_int8.npz` は2026年10月25日に追加学習・未使用データ評価を完了した既定モデルです。

- 118入力、96ユニット×2層GRU、時間特徴分岐、線形確率補正。
- 157,442パラメータ、167,276 bytes（163.4 KiB）。int8保存・float32 CPU推論。PyTorchは実行時に不要。
- 15口形＋内部HH（/h/系）とは独立した自然呼吸ヘッド。
- 先読み120 ms、推奨平滑化10 ms、100回/秒更新。
- SHA-256: `b3328c5b0749cd57cd67587b9b764bc7739b8dea5b5c9fbda48b79d29cba17a3`。
- 未使用テストの自動ラベル一致率: 日本語75.06%、英語63.14%、合算71.92%。無音以外の日本語は65.81%。
- 呼吸は評価可能な9録音中8録音を検出、陰性268録音中5録音で誤反応。人手の時刻ラベルではありません。

ユーザーの完了基準は「日本語75%以上、英語は補助」です。実際の唇の正解率75%を検証したものではありません。[評価・制約](../reports/RESULTS.md)、[追加学習コマンド](../docs/TRAINING_CURRENT_JA.md) を参照してください。

`baseline/kotoba_20261025.npz` は旧MLP、`candidates/` は途中の評価モデルです。CMN周波数補正・言語別ヘッド・大きなGRUは既定モデルには採用していません。
